MoLaView bundles one third-party runtime component, listed below.

Rendering uses a small purpose-built WebGL layer (webview/gl.ts and
webview/renderer.ts); toolbar icons are original inline SVG paths drawn to
match the Visual Studio Code icon metrics. No third-party fonts, icon fonts,
or 3D engines are included in the packaged extension.

Animated GIF export uses gifenc (https://github.com/mattdesl/gifenc), vendored
at webview/vendor/gifenc.js and bundled into the webview script:
